# v0.7 수치·범위 독립 대조 기록

2026-11-07 KST. 구현자와 별도 문맥의 read-only 검토자가 guide §9.16·§9.18과 catalog INT4/Strata 행을 지정 원자료와 대조했다. 이 기록은 Claude 검수나 GPU 재측정이 아니다.

확인한 교정은 하나다. catalog §4.6의 dequant 74.92% 분모를 ‘전체 9,716-token 요청’으로 읽을 여지가 있어 ‘가장 큰 9,711-token chunk의 event timeline’으로 명시했다. 원자료는 29,209/38,989 ms다. 가이드에는 이미 분모가 정확히 있었다.

검토 범위에서 INT4 같은 W4 계산 일치·표현 경로 실패·기존 W4 대비와 native 대비 비율, Strata 실제 J 변경·동일 J64 반복 변동·첫 요청과 warm·누계 I/O와 stage 배타 경계·자원 차단 상태의 불일치는 발견하지 못했다. Sparse §9.17과 최종 보호 SHA는 이 검토의 범위 밖이며 각각 자체 raw와 최종 감사 파일로 확인한다. root는 여섯 sym/aff sub-K 행의 범위를 재확인해 요약 배속을 1.80–2.03배로 표기했고, 대칭 세 행의 개별 숫자는 그대로 유지했다.
