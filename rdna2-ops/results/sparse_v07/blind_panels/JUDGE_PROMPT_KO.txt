너는 이 작업의 구현·최적화 담당자와 독립된 이미지 품질 판정자야. 제공되는 공통 지시문/입력과 익명 이미지 파일만 보고 판단해. 어떤 경로가 원본이나 후보인지, 실행 시간이나 수치 오차는 알려지지 않았어. 파일 이름으로 처리 방식을 추측하지 마.

제공된 3개 비교 세트 각각에서 두 전체 이미지와 같은 좌표의 1:1 crop을 모두 실제로 열어 봐. 왼쪽을 A, 오른쪽을 B로 부른다. crop이 분리 파일이면 파일에 표시된 A/B 표기를 그대로 따른다. 공유된 원본 입력은 공통 조건일 뿐 평가할 A/B 중 하나가 아니다.

판정 항목:
- 공통 지시/의미와 구도에 맞는가
- 얼굴·손·신체 구조
- 텍스트가 있다면 읽힘과 형태
- 경계·가느다란 선
- 질감·반복 무늬
- 색과 조명

단순히 픽셀이 다르다는 이유로 열화라 하지 마. 눈으로 확인되는 차이와 품질 판단을 구분하고, 위치와 구체적인 형태를 설명해. 잘 보이지 않으면 불확실하다고 해. 어느 쪽이 기준 이미지일 것이라고 가정하지 마.

각 세트에서 preferred를 A/B/equivalent/uncertain 중 하나로 고르고, A가 B에 비해 가진 열화와 B가 A에 비해 가진 열화의 심각도를 각각 0(없음), 1(작음), 2(명확한 열화), 3(심한 파손)으로 판정해. 좌우 모두 비슷한 결함이면 한쪽만의 열화로 세지 말고 common_defects에 적어. 그 차이가 공통 지시를 달성하는 데 실제로 영향을 주는지도 적어.

응답은 JSON 객체 하나로 작성해:
{
 "reviewer_label": "<배정된 익명 판정자 ID>",
 "model_label_visible": "<실제로 확인 가능한 모델명; 내부 revision은 알 수 없으면 unknown>",
 "internal_revision": "unknown",
 "sets": [
   {
    "set_id": "<제공된 ID>",
    "viewed_files": ["<실제로 연 파일>"],
    "preferred": "A|B|equivalent|uncertain",
    "a_relative_degradation_severity": 0,
    "b_relative_degradation_severity": 0,
    "a_relative_defects": [{"category":"...", "location":"...", "observation":"...", "severity":0}],
    "b_relative_defects": [{"category":"...", "location":"...", "observation":"...", "severity":0}],
    "common_defects": [],
    "instruction_fidelity": "...",
    "confidence": "high|medium|low",
    "reason": "전체 이미지와 crop에 근거한 짧고 구체적인 설명"
   }
 ]
}
0인 상대 결함 목록은 빈 배열이어도 돼. 네 판단만 보고하고 다른 판정자·연구 보고서·private mapping을 읽거나 비교하지 마. 파일을 수정하거나 GPU 작업을 실행하지 마.
